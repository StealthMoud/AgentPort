# AgentPort Development Roadmap

- Canonical Schema v1 & Fingerprinting Engine
- Client-Side Age (X25519) Vault Encryption
- Local Identity & Key Management
- Secret Scanner & Security Boundaries
- Codex, Claude Code, and Gemini CLI Adapters

- Encrypted Git Synchronization & Conflict Detection
- Complete E2E Cross-Machine Portability Suite

- Deep workspace context & custom rules scanning.

- LLM-assisted semantic deduplication, memory summarization, staleness analysis, and token-budget optimization with dry-run review.

## Phase 3 — Semantic Conflict Resolution
- Interactive 3-way semantic merge for cross-machine memory conflicts.

## Phase 4 — Continuous Synchronization
- Background daemon & live filesystem watcher.

## Phase 5 — Optional Management GUI
- Desktop interface for visual memory management and audit history.
